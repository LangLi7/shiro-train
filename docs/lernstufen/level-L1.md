# L1 — 1.–2. Klasse

## 1. Einordnung

| | |
|---|---|
| **Entspricht** | 1. und 2. Klasse der Primarschule |
| **Zyklus** | 1. Zyklus (mit Kindergarten); Dauer 4 Jahre |
| **Vorgänger** | [L0](level-L0.md) |
| **Nachfolger** | [L2](level-L2.md) |
| **Wichtige Grenze** | Ab der 3. Klasse wird benotet (L2) |

## 2. Lernstoff

### Mathematik
- **Zeichen und Begriffe**: `+`, `-`, `=`, „plus", „minus", „gleich"
  (`MA.1.A.1.b`); danach „mal", „grösser als", „kleiner als", „gerade",
  „ungerade", „ergänzen", „halbieren", „verdoppeln", „Zehner", „Einer", `·`,
  `<`, `>` (`MA.1.A.1.c`)
- **Zahlenraum**: natürliche Zahlen **bis 100** lesen und schreiben
  (`MA.1.A.1.c`)
- **Rechnen im Zahlenraum bis 20** ohne Zählen: verdoppeln, halbieren,
  addieren, subtrahieren (`MA.1.A.3.a`)
- **Rechnen bis 100 ohne Zehnerübertrag** (Beispiel aus dem Lehrplan:
  `35 + 13`), auf den nächsten Zehner ergänzen, zweistellige Zahlen in Zehner
  und Einer zerlegen (`MA.1.A.3.b`)
- **Zahlen zerlegen und umformen**: `5 = 1 + 4 = 3 + 2`; Kommutativgesetz
  `5 + 3 = 3 + 5` (`MA.1.A.4.b`)
- **Umkehroperation**: Addition als Umkehrung der Subtraktion nutzen
  (`18 - 15 = 3, weil 15 + 3 = 18`); Kommutativ- und Assoziativgesetz anwenden
  (`MA.1.A.4.c`)

### Sprache / Logik-Vorläufer
- **Wort- und Satzbau** untersuchen: Wortgrenzen, Anzahl Wörter im Satz
  (`D.5.C.1.b`)
- **Erste orthografische Regel** unter Anleitung untersuchen und ein erstes
  Regelverständnis entwickeln (z. B. `sp-`/`st-`, Grossschreibung)
  (`D.5.C.1.c`)

### Schlussfolgerndes Denken
- **Systematisch variieren**: „8 + 8 = 16, 8 + 9 = 17 — die Summe erhöht sich
  um 1, weil der zweite Summand um 1 zunimmt" (`MA.1.B.1.b`) — das ist der
  Kern von **Wenn-dann-Denken ohne Junktor**
- **Zahlenfolgen bilden und weiterführen** (figurierte Zahlen: 1,2,3 / 2,3,4 /
  3,4,5 / 4,5,6 — `MA.1.B.1.b`)
- **Summen bis 100 systematisch variieren** (`MA.1.B.1.c`)

### DACH-Vergleich (KMK / Österreich)

> **KMK (Deutschland) hat für diese Stufe *keinen* Anker.** Die KMK-Standards
> gelten für den Primarbereich **„am Ende von Jahrgangsstufe 4"** — also erst
> für L2. Für die 1.–2. Klasse gibt es **keine** KMK-Bildungsstandards.
> Quelle: [KMK Primarbereich (2022)](https://www.kmk.org/fileadmin/Dateien/veroeffentlichungen_beschluesse/2022/2022_06_23-Bista-Primarbereich-Mathe.pdf)

**Österreich — 1. Schulstufe (wörtlich):**

> „die Zahlen **bis mindestens 20** mit strukturiertem Material darstellen,
> lesen, schreiben, zerlegen, vergleichen, ordnen und vielfältig nutzen; die
> Zahlen **bis 100** mit strukturiertem Material darstellen, lesen und
> schreiben."

> „Rechenoperationen im additiven Bereich im Zahlenraum **bis mindestens 20**
> flexibel durchführen."

**Was das für L1 bestätigt:**

| Punkt | Bedeutung |
|---|---|
| Zahlenraum „**bis mindestens 20**" für Operationen | deckt sich mit `MA.1.A.3.a` |
| Lesen/Schreiben „bis 100" auf derselben Stufe | **genau die Zweiteilung von L1**: operieren bis 20, Zahlenraum bis 100 |
| „**mit strukturiertem Material**" | das AT-Pendant zum „ohne Zählen" des Lehrplans 21 |

## 3. Kann-Beschreibungen

Am Ende von L1 kann Shiro …

1. … **einstellig addieren und subtrahieren** im Zahlenraum bis 20, ohne den
   Weg abzuzählen.
2. … **zweistellig addieren und subtrahieren, solange kein Zehnerübertrag
   nötig ist** (`35 + 13`, `47 - 23`).
3. … eine Zahl **in Zehner und Einer zerlegen** und umgekehrt zusammensetzen.
4. … eine **Zahlenfolge mit konstanter Schrittweite** fortsetzen und die
   Schrittweite benennen („jede Zahl ist 2 grösser").
5. … eine **systematische Variation beschreiben** („wenn der Summand um 1
   steigt, steigt die Summe um 1").
6. … **Kommutativgesetz** anwenden: die Reihenfolge der Summanden ändern
   (`2 + 18 = 18 + 2`).

**Was L1 ausdrücklich nicht verlangt:** Zehnerübertrag (`MA.1.A.3.b` schliesst
ihn wörtlich aus), schriftliches Rechnen (erst `MA.1.A.3.d`, L2), das kleine
Einmaleins (erst `MA.1.A.3.d`).

## 4. Messindikatoren

| Indikator | Wert auf L1 |
|---|---|
| **Ziffernspanne** | 1–2 Stellen; Zahlenraum ≤ 100 |
| **Operationsumfang** | `+`, `-`; **kein** Übertrag, **keine** Multiplikation/Division; Verdoppeln und Halbieren |
| **Kettenlänge** | 2–3 Schritte (Zerlegen → rechnen → zusammensetzen) |
| **Regelkomplexität** | 1 Operation, 2 Operanden; Musterperiode 1–3; keine Negation als Operator |
| **Kontextbudget** | ≤ 120 Bytes je Datensatz |

## 5. Beispielaufgaben

**Addition ohne Zehnerübertrag (curriculare Grenze L1/L2):**
```
<AUFGABE> Rechne: 35 + 13 = ?
<DENKWEG> E 5+3=8 -> 8 u0 ; Z 3+1=4 -> 4 u0 ; R 48
<ANTWORT> 48 <ENDE>
```

**Zehnerübertrag — auf L1 gibt es dafür keinen Denkweg nach Lehrplan:**
```
<AUFGABE> Rechne: 47 + 58 = ?
<DENKWEG> E 7+8=15 -> 5 u1 ; Z 4+5+1=10 -> 0 u1 ; H 0+0+1=1 -> 1 u0 ; R 105
<ANTWORT> 105 <ENDE>
```
*Diese Aufgabe gehört auf **L2** (`MA.1.A.3.d`, schriftliches Addieren). Sie
steht hier als Gegenbeispiel, damit die Stufengrenze sichtbar ist.*

**Systematische Variation (L1-typisch):**
```
<AUFGABE> 8 + 8 = 16. Was ergibt 8 + 9?
<DENKWEG> 1. Der zweite Summand wird um 1 groesser. 2. Also wird die Summe um 1 groesser. 3. 16 + 1 = 17.
<ANTWORT> 17 <ENDE>
```

**Zahlenfolge mit konstanter Schrittweite:**
```
<AUFGABE> Zahlenfolge: 2 4 6 8 - wie lautet die naechste Zahl?
<DENKWEG> 1. Jede Zahl ist 2 groesser als die vorige. 2. 8 + 2 = 10.
<ANTWORT> 10 <ENDE>
```
