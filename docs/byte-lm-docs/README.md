# byte-lm-docs

Projektdokumentation für ein Byte-Level-Modell in Rust, aufgebaut für die Arbeit mit einem KI-Agenten.

## Benutzung

1. Ordnerinhalt ins neue Repository kopieren (`AGENTS.md` im Wurzelverzeichnis, `docs/` und `tasks/` daneben).
2. Dem Agenten sagen: "Lies `AGENTS.md` und bearbeite `tasks/phase-0-1-workspace-and-container.md`."
3. Eine Aufgabe pro Sitzung. Ergebnis selbst prüfen (Befehle laufen lassen), nicht nur dem Bericht glauben.
4. Nach jeder Aufgabe `docs/decisions.md` und die Roadmap aktualisieren lassen.

## Hinweise

- Wenn dein Harness eine bestimmte Kontextdatei erwartet (z. B. mit anderem Namen), kopiere `AGENTS.md` unter diesem Namen oder verweise darin auf sie.
- Kosten- und Zeitangaben in den Dokumenten sind Schätzungen. Crate-Namen und Backend-Unterstützung vor der Nutzung prüfen.
- Die genaue Funktionsweise von Jev ist noch offen (`docs/08-risks-and-open-questions.md`).
