# Datenquellen

Hinweis: Nicht alle Adressen wurden live geprüft. Lizenz jeder Quelle vor Gebrauch kontrollieren.

## Rust-Basics und Aufgaben mit Tests

- The Rust Book, Rust by Example
- Rustlings (kleine Übungen)
- Exercism, Rust-Track (Aufgaben mit fertigen Tests)

## Code in vielen Sprachen

- Rosetta Code (dieselbe Aufgabe in vielen Sprachen)
- GitHub: TheAlgorithms/Rust (Referenzalgorithmen)
- The Stack v2 (Hugging Face)

## Assembly

- Compiler Explorer (godbolt.org) zeigt den Zusammenhang Code ↔ Assembly.
- Besser und skalierbar: Paare selbst erzeugen mit `rustc --emit asm`. Exakt und gratis.

## Logik und Rechnen

- Reasoning Gym (GitHub): generiert Aufgaben mit automatisch prüfbarer Lösung. Existenz und Aktualität noch prüfen.
- Eigene Generatoren in Rust: Arithmetik, Logikrätsel, Algorithmen mit Referenzlösung.

## Sprache

- Tatoeba (tatoeba.org): Satzpaare in vielen Sprachen
- OPUS (opus.nlpl.eu): Übersetzungskorpora
- kaikki.org: Wiktionary-Extrakte (Wörterbuch)

## Programmierprinzipien und Code Smells

- refactoring.guru (Code Smells mit Vorher/Nachher)
- Rust API Guidelines (rust-lang.github.io/api-guidelines)
- Clippy-Lintliste (rust-lang.github.io/rust-clippy)
- Bücher: Clean Code, The Pragmatic Programmer, Refactoring (Fowler)

## Algorithmen

- Binary Search: Wikipedia, TheAlgorithms
- Autocomplete: Trie (Präfixbaum) mit Häufigkeitsranking, Stichworte "Trie" und "typeahead system design"
- Matrix Multiplication: naiv O(n³), Blocking/Tiling, Strassen. Praxis: Blogpost "How to Optimize a CUDA Matmul Kernel" (siboehm)
