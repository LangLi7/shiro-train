## 6. Backlog der nächsten Schritte (mit Akzeptanzkriterien)

### Punkt 1 — Backend und Backward-Pass (Burn) · **0 $, lokal**

**Ziel:** Burn gepinnt, echtes Modell S, echter Gradientenlauf.
**Akzeptanzkriterien:**
- Burn-Version **exakt gepinnt** (kein `*`) in `Cargo.toml`/`Cargo.lock`; `Cargo.lock` mitcommittet.
- Mini-Netz lernt eine UND-Verknüpfung auf CPU: Loss sinkt monoton über N Schritte, zweimal identisch (Digest).
- **Gradientenprüfung:** analytischer Gradient gegen numerische Ableitung innerhalb Toleranz (Test im Repo, nicht nur einmalig von Hand).
- Echtes Modell S (RoPE, RMSNorm, SwiGLU, Tiefe/Breite aus `configs/model.small.toml`) ersetzt den Platzhalter in `src/train/trainer.rs`; AdamW mit Warmup/Cosine, Weight Decay, Gradient Clipping wie in der Roadmap.

### Punkt 2 — `export`, `chat`, `eval` und Null-Baseline-Roundtrip · **0 $, lokal**

**Ziel:** Messpfad end-to-end beweisen, **bevor** GPU-Zeit anfällt.
**Akzeptanzkriterien:**
- Drei neue Subkommandos; Export erzeugt exakt `model.safetensors` + `config.json` + `special_bytes.json` + `run.json` + `SHA256SUMS` (`MODEL_FORMAT.md` §1).

- Der Roundtrip läuft **ohne Python im Container** (Prüfskript bleibt lokal/zugeliefert).

### Punkt 3 — `memmap2` und Gradient Accumulation · **0 $, lokal**

**Ziel:** Batchgrösse in Bytes überhaupt einstellbar machen, Loader von 2 GB entkoppeln.
**Akzeptanzkriterien:**
